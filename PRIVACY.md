# SaveToBuy Privacy Policy

Last updated: May 3, 2026

SaveToBuy is a Chrome extension that lets users save clothing products from shopping websites into a local closet.

## Single Purpose

SaveToBuy's single purpose is to help users save, organize, search, and revisit clothing products they find online before making a purchase decision.

## Information The Extension Handles

When a user chooses to save a product, SaveToBuy may store the following product information:

- Brand
- Product name
- Price and currency, when available
- Shipping fee, when available
- Product image URL
- Original product page URL
- Source website domain
- Date saved
- User-selected item status, such as liked, unliked, or waiting list

This information is saved so the user can view and organize saved clothing items in the extension's closet page.

## Local Storage Only

SaveToBuy stores saved product information locally in the user's Chrome browser using `chrome.storage.local`.

SaveToBuy does not operate a backend server for this MVP. Saved closet data is not uploaded to SaveToBuy servers.

## Website Access

SaveToBuy reads the active product page only after the user clicks the extension icon. The extension uses this access to extract product details such as product name, price, image, and product URL.

SaveToBuy does not continuously monitor browsing activity.

## Data Sharing And Sale

SaveToBuy does not sell user data.

SaveToBuy does not transfer saved closet data to third parties.

SaveToBuy does not use user data for advertising, creditworthiness, lending, or unrelated purposes.

## Accounts And Personal Information

SaveToBuy does not require users to create an account.

SaveToBuy does not intentionally collect personally identifiable information, health information, payment information, authentication information, personal communications, or location information.

## Remote Code

SaveToBuy does not use remotely hosted extension code. The extension's JavaScript and CSS are bundled with the extension package.

## Deleting Data

Users can delete individual saved products from the closet page. Users can also remove all locally stored extension data by uninstalling the extension or clearing extension site data in Chrome.
